---
title: 最初のページを作る
description: ReactアプリでHTMLをA4ページとして確認し、印刷またはPDFとして保存します。
---

既存のReactアプリにページプレビューを追加します。このガイドを終えると、HTMLをA4ページとして確認し、同じ結果をブラウザーの印刷画面から紙へ印刷またはPDFとして保存できます。

## 始める前に

React 18 以降と、ブラウザーで動作するクライアント環境が必要です。Imposia は Node.js やサーバーサイドレンダリングの処理中にはページを生成しません。

## 1. React パッケージをインストールする

```bash
pnpm add @imposia/react react react-dom
```

パッケージのスタイルシートは、コンポーネントまたはアプリのクライアントエントリーファイルで一度だけ読み込んでください。

## 2. ページ文書を表示する

```tsx
import { ImposiaPageViewer, type ImposiaPageViewerHandle } from "@imposia/react";
import { useRef } from "react";
import "@imposia/react/styles.css";

export function Preview() {
  const viewer = useRef<ImposiaPageViewerHandle>(null);

  return (
    <>
      <ImposiaPageViewer
        ref={viewer}
        source={{ html: "<article><h1>こんにちは</h1><p>ブラウザーネイティブなページ。</p></article>" }}
        documentOptions={{ page: { size: "A4", margin: "18mm" } }}
      />
      <button type="button" onClick={() => void viewer.current?.print()}>
        印刷 / PDF保存
      </button>
      <button
        type="button"
        onClick={() =>
          void viewer.current?.exportEpub({
            metadata: { title: "こんにちは", language: "ja", identifier: "urn:example:hello" },
          })
        }
      >
        EPUB を書き出す
      </button>
    </>
  );
}
```

`source.html` にはページにする内容を指定し、`documentOptions.page` には用紙サイズと余白を指定します。`viewer` ハンドルは、直近でページ分割に成功した文書を指します。

## 3. 結果を確認する

ブラウザーでコンポーネントを開き、HTML が A4 ページとして表示されることを確認してください。

- **印刷 / PDF保存**を押すと、Viewerに表示中のページを使ってブラウザー標準の印刷画面が開きます。紙に出す場合はプリンターを、ファイルに残す場合は**PDFとして保存**を選びます。このメソッドはPDFバイトを返しません。
- **EPUB を書き出す**を押すと、リフロー型 EPUB 3.3 `Blob` が返ります。この例では書き出しメソッドを呼ぶところまでしか扱いません。実際のアプリでは、返された `Blob` をダウンロードまたは保存処理につないでください。

`source` を更新しても、次の文書が完成するまでは現在のページが表示され続けます。アセットの読み込みや本番用の出力 UI を追加する前に、[プレビューと出力が一致する仕組み](/ja/docs/concepts/publishing-model)を確認してください。

コンポーネントの全 props、ハンドル、Core と Viewer の低レベル API は、[API リファレンス](/ja/docs/api)で確認できます。
