このページは、バージョン付きで公開された各 Imposia リリースを要約します。`@imposia/core`、`@imposia/viewer`、`@imposia/client`、`@imposia/react` は同じバージョン番号を使います。完全な記録はリポジトリの [CHANGELOG.md](https://github.com/EungyuCho/imposia/blob/main/CHANGELOG.md) です。

## 0.5.0 — 2026年8月20日

Core がブラウザーのネイティブパーサーで解析するようになり、ページ分割の性能改善で長い文書のレイアウト計測が減りました。

- `parse5` をブラウザーネイティブの解析（`DOMParser`、template フラグメント解析、ネイティブ直列化）に置き換えました。不正なマークアップは以前と異なる解析結果になる場合があり、`parse5` と `entities` は Core バンドルから外れました。
- 本番向け脆弱性監査で指摘された、同梱の `postcss` と推移的依存の `nanoid` を修正しました。
- 兄弟ノードの並びをまとまりごとに配置し、あふれたときだけ二分探索するようにして、ノードごとの強制同期リフローとインラインあふれ検査をなくしました。
- ページをまたぐテキストの分割位置を、書記素ごとの計測ではなく行ボックスの矩形から導出するようにしました。プロジェクトの長い段落のフィクスチャでは、`getClientRects` の呼び出しが英語テキストで 98.1%、CJK テキストで 95.9% 減りました。
- 同じ世代内の同一 URL のアセットで、リゾルバー呼び出し、デコード検証、Blob URL を 1 回に共有しました。出現ごとのバイト集計と、拡張機能による拒否の扱いは変わりません。
- ブラウザーバンドルを最小化し、バンドルサイズ予算を再設定しました。新しい高速経路には 1 リリースの間だけ内部フォールバックが同梱されるため、今回の Core バンドルは大きくなっています。

## 0.4.1 — 2026年7月27日

呼び出し側のビューポート制約下でも複数ページの印刷が安定し、Viewer のパネルがレスポンシブな操作バーに追従するようになりました。

- 呼び出し側が `html` と `body` に指定したビューポート制約が、隔離されたネイティブ印刷スナップショットを 1 枚に切り詰めないようにしました。ソース文書の印刷カスケードは維持されます。
- Viewer の目次、検索、サムネイル、Inspector の各パネルを、320 px の折り返しレイアウトを含む実際のレスポンシブ操作バーの下に配置するようにしました。
- ローカライズ済みドキュメントを、入門、基本概念、出版ガイド、パッケージ API リファレンス、ブラウザー標準の PDF 保存を軸に再構成しました。

[0.4.1 のリリースノート](https://github.com/EungyuCho/imposia/releases/tag/v0.4.1)

## 0.4.0 — 2026年7月24日

協調的なページ分割により、確定されるページ構造を変えずに、長い HTML や CSR 更新でも応答性を保てるようになりました。

- `PageDocumentOptions.compose` に、既定 8 ms の実行予算、差し替え可能なスケジューラー、スケジューラーへの移譲を無効にする `Infinity` 指定を追加しました。
- 完了したページ数と収束パスを含む暫定的な進捗通知を追加しました。
- ステージングの内容とスタイルをマウントした後に、フォントと画像の読み込み完了を待つようにしました。
- スケジューラー待機を中止できるようにし、追い越す世代どうしを直列化してから勝った世代をステージングするようにしました。
- ネイティブ印刷スナップショットで、ソースの `html`・`body` コンテキスト、body スコープのセレクター、計算済みカスタムプロパティを保持するようにしました。
- ページをまたぐカウンターが動作し続けるよう style containment は無効のまま、確定済みページのルートに layout containment を追加しました。

[0.4.0 のリリースノート](https://github.com/EungyuCho/imposia/releases/tag/v0.4.0)

## 0.3.0 — 2026年7月24日

印刷が iframe のサイズから独立し、制約付きのテーブル構成に明示的な拡張フックが加わりました。

- Chromium で印刷が白紙になる問題を避けるため、ネイティブ印刷をトップレベル文書内の一時的で隔離されたスナップショットへ移しました。
- Core と Publication の拡張機能向けに、同期の `finalizePage` フックを追加しました。
- 分割されたテーブルの列幅を安定させる、明示的に有効化する `createTableColgroupExtension()` プリセットを追加しました。
- 分割テーブル、安全な Grid、ページより高い通常ブロックの分割で、現在のページの残り領域を使うようにしました。

[0.3.0 のリリースノート](https://github.com/EungyuCho/imposia/releases/tag/v0.3.0)

## 0.2.0 — 2026年7月24日

Viewer の操作 UI をホストアプリケーション側で完全に構成できるようになりました。

- 独自のナビゲーション、表示モード、ズーム UI を持つホスト向けに `controls: false` を追加しました。
- 即時の Viewer 状態購読、React の状態コールバック、命令型のナビゲーションとズーム操作を追加しました。
- Viewer のトークンと表示スタイルを各 Viewer ルートに限定し、スタイルシートの読み込みがホストページを変えないようにしました。

[0.2.0 のリリースノート](https://github.com/EungyuCho/imposia/releases/tag/v0.2.0)

## 0.1.3 — 2026年7月23日

HTML と CSR のページ分割の整合性を、製品の第一の契約にしました。

- ソースのトークンが確定済みページ全体に一度ずつ、元の順序で現れることを証明するブラウザー横断の継続性テストを追加しました。
- canonical iframe を保持したまま高速なソース更新を適用する、公開 CSR 継続性サンプルを追加しました。
- リフロー型 EPUB を、看板のレンダリング経路ではなく、サポートされる意味構造の投影として位置付けました。

[0.1.3 のリリースノート](https://github.com/EungyuCho/imposia/releases/tag/v0.1.3)

## 0.1.2 — 2026年7月23日

リリース検査とデモサーバーのセキュリティ姿勢を強化しました。

- 検証とコードスキャンに加えて、CodeRabbit の自動レビューを追加しました。
- 未使用だったデモサーバーの要求遅延機能を削除し、関連する CodeQL 指摘を解消しました。
- 構造セレクターが、保守的なフォールバックを持つ `Element.matches()` だけに到達することを確認しました。

[0.1.2 のリリースノート](https://github.com/EungyuCho/imposia/releases/tag/v0.1.2)

## 0.1.1 — 2026年7月23日

デモ、ドキュメント、リリース経路を公開パッケージの更新に備えて整えました。

- 縦向きを優先する A4 操作、向きの切り替え、A3・A4・B1 プリセットを追加しました。
- 多言語の API ドキュメントと出版ドキュメントを拡充しました。
- npm trusted publishing、タグ、GitHub Releases、tarball、チェックサムを備えた、保護付きの GitHub Actions リリース経路を追加しました。

[0.1.1 のリリースノート](https://github.com/EungyuCho/imposia/releases/tag/v0.1.1)

## 0.1.0 — 2026年7月19日

最初のブラウザー専用リリースで、公開パッケージ群の全体を確立しました。

- 1 つの永続的な canonical iframe による決定的なブラウザーページ分割を追加しました。
- Viewer の表示層、ブラウザー用 Client エントリーポイント、主要な React アダプターを追加しました。
- Publication の構成、Reader のナビゲーション、検索、サムネイル、複数の表示モードを追加しました。
- 確定したソースからのネイティブ印刷とリフロー型 EPUB 3.3 書き出しを追加しました。
- 型付きの診断、境界のある拡張機能、アセット解決、制約付きのテーブル・Flex・Grid・段組み・CJK 分割を追加しました。

[npm で @imposia/core 0.1.0 を見る](https://www.npmjs.com/package/@imposia/core/v/0.1.0)
