title: Imposia ドキュメント

---

Imposia は HTML と CSS をブラウザー内でページに分割します。プレビューと印刷には完成したページを使い、EPUB には同時に確定したソースの意味構造を使います。

## 目的から選ぶ

- **まずプレビューを動かす：** [最初のページを作る](/ja/docs/getting-started)に沿って React パッケージをインストールし、HTML を A4 ページとして表示してください。
- **API の型とメソッドを調べる：** [API リファレンス](/ja/docs/api-reference)で React、Core、Viewer の公開 API と利用条件を確認してください。
- **出力の仕組みを理解する：** 印刷、EPUB ダウンロード、外部アセットを組み込む前に、[プレビューと出力が一致する仕組み](/ja/docs/publishing-contract)を確認してください。

## HTML がページになるまで

1. アプリから HTML、CSS、ページ設定を Imposia に渡します。
2. Core が準備用の iframe で次の文書をページ分割します。
3. ページ分割が完了すると、Imposia が表示中の文書を一度に置き換えます。

ページ分割に失敗した場合や、処理中の更新がさらに新しい更新に置き換えられた場合も、直前に完成した文書を表示し続けます。計算途中のレイアウトが画面に現れることはありません。

## 1 つの確定したソースを 3 つの用途に

- **プレビュー：** React Viewer で完成したページを表示します。
- **印刷：** 同じページを対象にブラウザーの印刷ダイアログを開きます。
- **EPUB：** 最後に確定したソースの意味構造から、リフロー型 EPUB 3.3 `Blob` を作成します。

## 対応範囲を確認する

Imposia はブラウザー内で動作し、ESM として提供されます。Node レンダラー、CLI レンダラー、サーバー側の出力 API、PDF ジェネレーターは含まれません。この構成がアプリに合う場合は、[最初のページを作る](/ja/docs/getting-started)へ進んでください。
