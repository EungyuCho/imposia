Imposia는 쓰던 HTML과 CSS를 브라우저 안에서 페이지로 만듭니다. React 앱에서 페이지를 미리보고, 브라우저 인쇄 창으로 보내거나 **PDF로 저장**할 수 있습니다. EPUB은 같은 페이지와 함께 확정한 원본의 의미 구조로 만듭니다.

## 먼저 읽을 문서를 고르세요

- **페이지를 바로 만들어 보고 싶다면:** [첫 페이지 만들기](/ko/docs/getting-started)를 따라 React 패키지를 설치하고 HTML을 A4 페이지로 표시해 보세요.
- **컴포넌트와 메서드를 찾고 있다면:** [API 레퍼런스](/ko/docs/api)에서 React, Core, Viewer의 시그니처와 준비 조건을 확인하세요.
- **출력 방식부터 이해하고 싶다면:** 인쇄, EPUB 다운로드, 외부 에셋을 연결하기 전에 [미리보기와 출력이 일치하는 방식](/ko/docs/concepts/publishing-model)을 읽어 보세요.

## HTML을 넘기면 이렇게 처리합니다

1. 앱이 HTML, CSS, 페이지 설정을 Imposia에 전달합니다.
2. Core가 임시 iframe에서 다음 문서의 페이지를 계산합니다.
3. 모든 페이지를 만든 뒤 화면에 보이는 문서를 한 번에 바꿉니다.

페이지를 만드는 도중 오류가 나거나 더 새로운 요청이 들어오면 이전 문서를 그대로 보여줍니다. 계산이 끝나지 않은 레이아웃은 화면에 나타나지 않습니다.

## 같은 문서를 세 가지로 활용합니다

- **미리보기:** React Viewer에서 완성된 페이지를 보여줍니다.
- **인쇄 또는 PDF 저장:** 화면에 보이는 페이지로 브라우저의 기본 인쇄 창을 엽니다. 프린터를 선택하면 종이로 출력되고, **PDF로 저장**을 선택하면 파일로 남습니다.
- **EPUB:** 마지막으로 확정한 원본의 의미 구조로 리플로우형 EPUB 3.3 `Blob`을 만듭니다.

## 시작 전에 범위를 확인하세요

Imposia는 브라우저에서 ESM으로 실행됩니다. `print()`는 브라우저의 기본 인쇄 기능을 사용하며 PDF 바이트를 반환하지 않습니다. Node 렌더러, CLI 렌더러, 서버 출력 API, 별도의 PDF 생성기도 없습니다. 이 범위가 앱에 맞다면 [첫 페이지 만들기](/ko/docs/getting-started)로 이어가세요.
