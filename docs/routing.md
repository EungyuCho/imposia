# Documentation routing

- System architecture overview: [architecture/overview.md](architecture/overview.md). It maps the package topology, the staged-to-committed pagination pipeline, the security boundary, the extension runtime, Publication and output surfaces, the five integrity invariants and their mechanisms, verification layers, and the build-time enforcement scripts. It is descriptive; ADRs remain authoritative for decisions.
- Product and public contracts: [domain/product.md](domain/product.md). It defines HTML/CSR pagination integrity as the primary product contract, the React-first browser package, framework-neutral Core/Client/Viewer contracts, canonical iframe lifecycle, and semantic EPUB export.
- Product roadmap: [roadmap.md](roadmap.md). It orders post-`0.5.0` work by product risk, names milestones by outcome (Publish, Proof, Adoption, Contract, `1.0`) rather than by version number, defines each milestone's exit criteria, and carries the prioritization rule that settles competing work.
- Public API stability before `1.0`: [api-policy.md](api-policy.md). It defines what counts as public surface, what a `0.x` minor and patch are each allowed to change, what a breaking change owes a consumer, and the shorter clock that applies to `experimental.*`.
- Consumer upgrade paths: [migrations/](migrations/). One note per release that carries a breaking change — currently [`0.5.0`](migrations/0.5.0.md), covering the browser-native parser replacement and the bundled-dependency security patch.
- Open-source launch work: [open-source-readiness.md](open-source-readiness.md). It separates the completed client release gate, post-release engineering follow-ups, and maintainer-controlled launch gates.
- Compatibility matrix: [compatibility.md](compatibility.md). It is authoritative for Stable, Experimental, Constrained, and Unsupported page-media, fragmentation, publishing, export, and browser behavior.
- Browser bundle report and gzip budgets: [bundle-size.md](bundle-size.md). It defines the measured consumer routes, reproducible command, budget policy, and current EPUB size decision.
- Clean-room policy: [clean-room.md](clean-room.md)
- Architecture decisions: [project name](architecture/0003-imposia-name.md), [browser-first page DOM target and implementation status](architecture/0004-browser-first-page-dom.md), [browser publishing contract](architecture/0006-browser-publishing-contract.md), [Publication source boundary](architecture/0007-publication-source-boundary.md), [Publication outline authority](architecture/0008-publication-outline-authority.md), [Publication page identity](architecture/0009-publication-page-identity.md), [cooperative pagination](architecture/0012-cooperative-pagination.md), and [browser-native string-domain parsing](architecture/0013-browser-native-parsing.md)
- EPUB package and bundle boundary: [ADR 0010](architecture/0010-core-epub-bundle-boundary.md)
- Primary HTML/CSR pagination-integrity contract and public proof requirements: [ADR 0011](architecture/0011-html-csr-pagination-integrity.md)
- Ordered Core extension runtime and its security boundaries: [ADR 0005](architecture/0005-core-extension-contract.md)
- Verification evidence: [verification.md](verification.md)
- Documentation and localization release audit: [documentation-localization-audit.md](documentation-localization-audit.md)
- Public website: `site/` is a Vite-powered React Router SPA (`ssr: false`) using Fumadocs layouts and localized MDX at `/en`, `/ko`, `/zh-CN`, and `/ja`. Public documentation follows the reader journey (`getting-started`, `concepts`, `guides`) and groups package references under `api/react`, `api/core`, and `api/viewer`. Cloudflare Pages redirects the former flat API and publishing URLs to this hierarchy.
